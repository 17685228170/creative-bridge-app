# 创意桥 - 本地部署说明

## 🚀 快速启动

### 方式1：双击启动（推荐）
1. 双击 `启动.bat`
2. 等待安装依赖和初始化
3. 浏览器自动打开 http://localhost:3000

### 方式2：命令行启动
```bash
# 安装依赖
npm install

# 初始化数据库
npx prisma migrate dev
npx prisma db seed

# 启动服务器
npm start
```

---

## 📋 系统要求

- **Node.js**: v18 或更高版本
- **内存**: 4GB+
- **磁盘**: 1GB 可用空间
- **浏览器**: Chrome / Edge / Firefox 最新版

## ⚠️ 注意事项

1. **首次启动**需要安装依赖，可能需要几分钟
2. **数据库**保存在 `prisma/dev.db`，请勿删除
3. **上传文件**保存在 `uploads/` 目录
4. **端口**默认 3000，如果被占用会自动切换到 3001

---

## 🔧 常见问题

### Q: 启动失败，提示缺少 Node.js
A: 访问 https://nodejs.org/ 下载并安装 LTS 版本

### Q: 数据库错误
A: 删除 `prisma/dev.db` 后重新运行启动脚本

### Q: 端口被占用
A: 脚本会自动切换端口，或手动修改 `.env` 文件

### Q: 如何停止服务器
A: 在命令行窗口按 `Ctrl+C`，然后按 `Y` 确认
